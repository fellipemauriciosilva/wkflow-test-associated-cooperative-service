# Workflow Test - Associated Cooperative Service

A Java-based workflow test service for the associated cooperative system.

## Building

```bash
mvn clean package
```

## Running Tests

```bash
mvn test
```

## Project Structure

- `src/main/java/com/example/acs/service/` - Main service implementations
- `src/test/java/com/example/acs/service/` - Service tests
