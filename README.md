# Cooperative Voting System – Phase 1: Associate & Assembly Foundation

## Overview

Foundational domain entities (Associate, Assembly) with CRUD operations, hexagonal architecture, and complete test coverage. This slice establishes the architectural patterns and development practices for subsequent slices.

**Status**: Phase 1/6 – Foundation Layer

## Tech Stack

- **Language**: Java 21 LTS
- **Framework**: Spring Boot 3.4.3
- **Database**: PostgreSQL 16
- **Schema Migrations**: Flyway 10.x
- **Testing**: JUnit 5, Mockito, Testcontainers 1.20+
- **API Documentation**: Springdoc OpenAPI 2.8+ (Swagger UI)
- **Build Tool**: Maven 3.9+
